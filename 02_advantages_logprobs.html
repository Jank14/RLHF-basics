Slicing values and log-probs

One sample: prompt "This is" (prefix_len = 3 with the BOS token) + 5 generated tokens. Every off-by-one in the notebook lives on this page.

Drag a value cell up/down (or click it and use ↑ ↓) to change the critic's forecast at that position.

1 · One value per position

values has shape (batch, seq_len): the value head runs on every position. values[i] = forecast of the final reward after reading tokens 0…i.

2 · Which values are "before an action"?

The first action is token 3 (" a"). The state before it ends at position 2. So the zero-step values are values[:, prefix_len-1 : -1] = positions 2…6.

3 · Which are "after an action"?

After each action the forecast is the next value: positions 3…6, values[:, prefix_len : -1]. The last action has no next forecast: glue on the real reward.

one_step_q_est = t.cat(
  [values[:, prefix_len:-1], rewards[:, None]], dim=-1)

4 · Subtract

advantages = one_step_q_est - zero_step_value_est: shape (batch, gen_len), one per generated token. A token that raised the forecast gets a positive advantage.

5 · They telescope

Adding them up, every middle value cancels: Σ A = r − V(prompt). The whole surprise is shared out to the tokens where the forecast moved. Change r: only the last advantage changes.

6 · Never used: the last value

values[:, -1] (after the final token) is never used: we have the real reward there instead.

returns = advantages + values[:, -gen_len-1:-1] = the one-step row: the critic is trained to predict its own next forecast, and r at the end.

Toy log-prob numbers. The pattern of the slicing is exactly the notebook's.

1 · A logit predicts the NEXT token

The model's output at position i is its guess for token i+1. So the log-prob of token 4 (" list") is read from the output at position 3.

2 · Skip what the model didn't choose

The prompt was given, not chosen. The first generated token is at position prefix_len, so we start reading outputs at prefix_len - 1:

logits = logits[:, prefix_len - 1:]
tokens = tokens[:, prefix_len - 1:]

3 · Gather the chosen token's log-prob

For each kept position s, take logprobs[b, s, tokens[b, s+1]]. The very last output has no s+1, so it drops out.

eindex(logprobs, tokens, "b s [b s+1]")
# → (batch, gen_len)

4 · Same positions: gen_len_slice

The trainer slices logits, values and ref_logits with slice(-gen_len-1, -1). Those are the same positions highlighted here: the outputs that predict generated tokens.

5 · Try another prefix_len

Move the slider. prefix_len = 1 (or None) keeps every prediction: shape (batch, seq_len − 1).
